# bitcoin on-chain data free

Sono disponibili numerose piattaforme che offrono **dati on-chain Bitcoin gratuiti** tramite dashboard web e API, ideali per analisi di trend, flussi di exchange e movimenti dei wallet. Qui trovi le fonti principali e le metriche ottenibili gratuitamente:[^1][^2][^3][^4][^5][^6][^7]

## Strumenti e Dashboard Gratuiti

- **CryptoQuant**: accesso gratuito a metriche come riserve degli exchange, SOPR (profit/loss dei detentori), NUPL e più, con dati aggiornati anche al giorno corrente previa registrazione.[^6][^1]
- **LookIntoBitcoin**: dashboard con indicatori chiave come MVRV-Z Score, HODL Waves, NUPL; nessun login richiesto.[^1]
- **BGeometrics Bitcoin API Free**: accesso API alle principali metriche on-chain (price, realized price, SOPR, MVRV Z-Score, Puell Multiple, hashrate, HODL Waves, address activity), esportazione CSV disponibile.[^4]
- **Blockchain.com Explorer e API**: consulta dati su blocchi, transazioni, wallet ed utilizza API REST/WebSocket (free) per metriche come hashrate, block height, difficoltà, nuovi blocchi.[^3][^8]
- **Bitbo.io**: visualizzazione live del prezzo BTC, dati on-chain aggiornati e indicatori economici senza registrazione.[^5]
- **Tokenview**: motore di ricerca su blockchain con report transazioni, address, news, API pubbliche.[^9]
- **Coinglass**: dashboard on-chain con dati su futures, open interest, funding rate, liquidazioni, e portafogli.[^10]


## Alternative API e Dati Scaricabili

- **Blast API**: endpoint RPC pubblici per Bitcoin, accesso gratuito, nessuna registrazione richiesta.[^11]
- **CryptoDataDownload**: time series storiche (giornaliere, orarie, minuti) di dati BTC e altri asset scaricabili gratis.[^12]
- **Blockstream.info**: block explorer open source, dati dettagliati su Bitcoin, Testnet e Liquid; nessun tracciamento.[^13]


## Indicatori On-chain Disponibili

- Flussi exchange in/out, netflow
- Movimenti grandi wallet (accumulazione/distribuzione)
- Nuove address, address attive, supply in profit/loss
- Volumi transazionali, SOPR, NUPL, HODL Waves
- Hashrate, block difficulty, miner revenue
- Open interest, liquidazioni futures

## Sintesi Operativa

Per monitorare BTC on-chain con strumenti gratuiti: usa CryptoQuant/LookIntoBitcoin per analisi grafiche, Blockchain.com o BGeometrics per API e automazioni, Bitbo per dashboard sintetica, Blast API per raw data e CryptoDataDownload per serie storiche.[^2][^3][^4][^12][^11][^5][^6][^1]

Tutti questi strumenti sono utilizzabili senza abbonamento premium; in caso di esigenze avanzate, è possibile valutare piani a pagamento o custom data.
